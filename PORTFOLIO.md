# A1 Portfolio View

## What this project demonstrates

A1 is a bounded, AI-assisted statistical-integrity evaluation artifact built around 24 selected cases arranged as 12 designed matched contrasts. It combines statistical reasoning, reproducibility engineering, evidence provenance, independent analytical recomputation, adversarial review, and controlled publication.

**Live interactive explorer:** https://fshofi.github.io/A1-Statistical-Integrity-Evaluation/

## Work performed

- Designed and governed a 24-case / 12-contrast statistical evaluation protocol.
- Preserved prompt/response provenance and hash-bound definitive run evidence.
- Separated deterministic parser coverage from independent quantitative recomputation and semantic/statistical review.
- Localised material, minor, and assumption-boundary defects without collapsing reviewer disagreement into a single score.
- Built a publication-safe GitHub release with privacy sanitisation, reproducibility controls, explicit limitations, and AI-assistance disclosure.
- Built an interactive Plotly evidence explorer using the CVDNA Plotly/Dash Visual Intelligence System v1.1.

## Selected release evidence

- 24/24 definitive responses preserved and hash-bound.
- 19/20 requested quantitative outputs correct by independent analytical recomputation.
- 23/24 final verdicts statistically defensible in the attributed review synthesis.
- 11/12 selected matched contrasts showed defensible verdict-level discrimination in both arms.
- Q195 retained as a substantive Bayes failure.
- Q361 retained as a minor supplemental numeric defect.
- Q976 retained as a minor invalid alternative-repair branch.
- Q731 retains disclosed assumption/reference dissent.

## Skills evidenced

**Data Science / Statistics:** statistical reasoning, Bayes, regression, uncertainty, causal/associational boundaries, leakage, metrics, assumptions, failure analysis.

**AI Evaluation:** matched-contrast design, case-level adjudication, model-response analysis, reviewer disagreement, failure localisation, bounded claims.

**Reproducibility / Governance:** provenance, hashing, replay, change control, privacy sanitisation, public/private evidence separation, release discipline.

**Visual Intelligence:** Plotly-based interactive evidence exploration, KPI hierarchy, case filtering, evidence-layer separation, limitations-first presentation.

## Claim boundary

A1 is a selected-case evaluation framework and portfolio/research artifact. It is not a validated population benchmark, a psychometric instrument, a universal measure of model competence, or evidence of production/enterprise deployment performance.
