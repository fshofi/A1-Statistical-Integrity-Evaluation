# Public/private evidence boundary

The public freeze includes the exact Amendment 1.1 source archive, the complete Run 1 evidence package, case prompts/responses, source code, tests, policies, review documents, and derived verification results.

The full evidence-closure ZIP is **not embedded** because its original rollout logs contain unnecessary platform-internal metadata, hidden instruction material, local filesystem paths, and activity records that are not required for public reproduction. The archive remains privately retained and is identified by SHA-256 `55a1dc44ee440bbc0db893667fa396428e1a07ee45ead903bc74b0edfe178c83`.

This exclusion is a publication-security decision, not an evidence gap. Final adjudication verified 24/24 original traces against the closure archive before freezing this public package.
