# A1 Plotly Companion

This directory is the first implementation of the **CVDNA Plotly/Dash Visual Intelligence System v1.1**.

## Purpose

The companion converts the frozen A1 publication findings into an interactive evidence surface without changing benchmark evidence, adjudication, scores, or limitations.

It implements the v1.1 operating principles of:

- one screen / one primary decision;
- KPI summary before detail;
- matched-pair exploration rather than treating 24 cases as iid observations;
- explicit separation of deterministic parser coverage, independent recomputation, and semantic/statistical judgement;
- visible limitations and retained dissent;
- restrained interaction that reveals evidence.

## Open

Open `index.html` in a modern browser with internet access. Plotly.js is loaded from the official Plotly CDN.

## Public claim boundary

The companion is a presentation and inspection layer only. It does not reopen A1, rescore cases, modify the frozen processor, or alter the publication freeze.

The bounded findings visualised are:

- 24/24 definitive responses preserved and hash-bound;
- 19/20 requested quantitative outputs correct by independent analytical recomputation;
- 23/24 final verdicts statistically defensible in the attributed review;
- 11/12 selected matched contrasts showed defensible two-arm verdict discrimination;
- Q195 material Bayes defect;
- Q361 supplemental numeric defect with requested outputs intact;
- Q976 one invalid alternative repair branch;
- Q731 assumption/reference dissent retained.

The frozen deterministic parser evaluated 0/20 numeric-applicable prose responses. This is **parser coverage, not 0% model accuracy**.
