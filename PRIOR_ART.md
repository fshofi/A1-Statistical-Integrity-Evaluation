# Prior art and originality boundary

## Broad originality statements

| Statement | Assessment | Boundary |
|---|---|---|
| A1 invented statistical LLM evaluation | NOT SUPPORTED | Statistical LLM benchmarks predate A1. |
| A1 invented causal-reasoning evaluation | NOT SUPPORTED | Prior benchmarks evaluate statistical and causal reasoning with data. |
| A1 invented process-based evaluation | NOT SUPPORTED | Process/fine-grained reasoning evaluation predates A1. |
| A1 invented evaluation beyond final-answer accuracy | NOT SUPPORTED | Prior work explicitly evaluates reasoning and intermediate process. |
| A1 contributes a compact matched statistical-integrity set with provenance, repair governance, replay, failure localization, hostile review, and bounded publication controls | SUPPORTED WITH QUALIFICATION | Support is for this assembled artifact and workflow, not field-wide novelty or priority. |

Relevant boundaries include StatEval (`https://arxiv.org/abs/2510.09517`) and QRData (`https://arxiv.org/abs/2402.17644`). This is a bounded prior-art assessment, not an exhaustive novelty search.
